# Project 14 Workstream Ownership

## Senior Backend Developer Workstream
1. API contract enforcement and schema validation.
2. Service-layer architecture and deterministic decision logic.
3. Repository abstraction (in-memory plus Supabase adapter).
4. Automated tests, benchmark script, and reliability guardrails.

## Frontend Developer Workstream
1. Type-safe API integration layer.
2. State management and async orchestration UX.
3. Responsive layout with clear decision visibility.
4. Build pipeline and production bundle verification.

## UI Developer Workstream
1. Visual language and information hierarchy for operator console.
2. Segment-aware visual cues and readable data density.
3. Mobile and desktop layout behavior.
4. Accessibility-aware forms, contrast, and interaction states.

## Handoff Standard
1. Each workstream updates DELIVERABLES.md with evidence links.
2. No workstream can claim complete unless CHECKPOINTS gate criteria are green.
3. REQUIREMENTS.md remains frozen unless full re-baseline is approved.
